## Research (the "looking online" part — sources in the ledger)

Web-searched 4 topic areas (26 sources; snippets recorded to
/home/z/my-project/scripts/research-*.json — sandbox artifacts, not
repo files). Principles extracted and applied:

- **Hero KPI top-left, 5-7 KPI max, visual hierarchy by
  size/color/position** (ThoughtSpot, Resolution, Context.dev,
  DataCamp) → attendance becomes a large gradient hero tile; the
  other four stay secondary tiles.
- **Real-time UX = freshness + stability + context + trust;
  200-400 ms transitions** (Smashing Magazine, FuseLab, UX Matters)
  → feed rows slide+fade in (280 ms), badge honesty kept, relative
  "just now → N min ago" context for live arrivals, chip tones.
- **Lightweight vector icons + color-coding** (UX Matters) → five
  16px inline stroke SVGs on the KPI tiles; event chips colored by
  type via ONE CSS attribute-selector mapping
  (`data-event-type^="CLASS_|PAE_|RECYCLING_|CARD_"`).
- **Empty states teach and direct** (NN/g) → icon + explanation
  pattern; waiting feed row stays honest.
- **Every async action needs visible loading feedback** (micro-
  interaction research) → per-button spinner (`is-loading`) on
  reader mode change, NL ask, redeem, and pairing arm — exactly the
  duration of the actual fetch.
- **Mobile: 44 px touch targets, card layouts, cut not add**
  (FuseLab, Querio, Toptal) → nav pills 44 px, buttons 48 px,
  `data-stack` tables become labeled cards at <620 px (no more
  horizontal scrolling), KPI strip 2-up then 1-up.
- **Forms: inline errors, aria-invalid** (NN/g, Baymard,
  TetraLogical) → kept + added password reveal and click-to-fill
  demo chips on login.
