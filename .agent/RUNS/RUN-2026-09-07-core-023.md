## En-route fixes and traps

- Git filemode noise (OBS-009): 391 files showed modified with 0
  content changes at pre-flight → `core.filemode false` locally (never
  committed) before touching anything.
- Material Symbols subsetting trap: pyftsubset with `--text` alone kept
  the font at 3.3 MB because the VARIABLE deltas are the bulk — the
  fix is instancing the axes (wght 400, FILL 0, GRAD 0, opsz 24) after
  subsetting (283 KB). Ligature verification must resolve
  ExtensionSubst wrappers (raw `.ligatures` iteration reports zero on
  this font). HarfBuzz shaping does not apply rlig for Latin in the
  bare test harness, but browsers apply required features — the font
  is the standard Google asset mechanism, and the ligature rules are
  verified present for all 27 icons.
- DemoSeeder already mints 1:1 student accounts (users.student_id
  UNIQUE) — tests must look them up, not create them.
- LeaderboardService ranks from the POINTS LEDGER, not deposits: the
  new-page test had to seed the ledger twin of the deposit.
- The 8 mockup documents were concatenated in one paste file; split on
  DOCTYPE boundaries before analysis.
