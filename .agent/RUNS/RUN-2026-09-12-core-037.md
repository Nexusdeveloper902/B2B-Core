# RUN-2026-09-12-core-037 — Spacing audit + crammed-spot fixes

Owner (chat, 2026-09-12): "The spacing is still looking inconsistent in
a lot of places. Go through each one and audit them, stuff should not
be crammed together."

## Audit method
- Browser pass over /login, /admin, /dashboard (22-class teacher view),
  /admin/students, /admin/readers, /admin/pairing, /admin/ecostation,
  /student, /student/rewards, parent timeline, 404 — desktop 1366px and
  mobile 390px — with an automated cramp detector (flags stacked
  sibling gaps < 7px) plus computed-style measurement of the suspect
  junctions.
- Source-level check of the flagged rules in app.css.

## Root causes found (6 defects)
1. **Headings had NO line-height** — h1–h4 inherited the body's 24px
   line box, so 40px lede titles overflowed their line box upward and
   the kicker collided with the title's ascenders on EVERY page
   (worst on the student hub and ES ledes). Fix: `h1,h2,h3,h4
   { line-height: 1.2 }` in the base rule. Systemic.
2. **Topbar wrapped under ES** — "CERRAR SESIÓN" broke onto two lines
   and the user name wrapped ("School / Admin") because long ES nav
   labels squeezed the tools cluster. Fix: `.logout-btn` nowrap +
   flex-shrink 0; `.topbar-user-name` nowrap (clips at its 220px
   max-width instead of wrapping).
3. **tool-form / file-row gaps were 4px** — create/import controls
   nearly touching inside 24px-padded panels. Fix: gap → `--sp-xs`
   (8px).
4. **Readers desk action cells crammed** — "ROTAR CLAVE" wrapped to
   two lines inside a ~70px column and buttons nearly touched the mode
   select. Fix: `.row-actions` is now a deliberate single-column of
   full-width, single-line small buttons (readers-only class, so no
   side effects).
5. **Rewards card note against the meter** (4px) — `.reward-note`
   now carries `margin-top: --sp-sm`.
6. **Orphaned "REWARDS →" link** floating alone below the student
   hub grid. Fix: new optional `footer` slot on the shared `x-stat`
   component (ADR-014 pattern); the balance hero card now carries the
   gold REWARDS → action; the stray paragraph is removed.

## Deliberately left alone
- Lede h1→subtitle 4px, stat label→value 4px, live-row 2px hairlines:
  designed tight pairs, consistent everywhere (mockup grammar).
- Full-bleed ledger tables (negative-margin .ledger-wrap): intended
  edge-to-edge grammar, not a defect.
- Teacher class cards' internal rhythm measured correct (24px panel
  padding, 16px chips→table).
