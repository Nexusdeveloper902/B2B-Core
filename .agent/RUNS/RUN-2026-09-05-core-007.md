## What was actually wrong

Nothing was red — and that was the trap. A fresh dispatch on main
(33922483187) proved **13/13 success**, and the local mirror
(`./run doctor`, `./run ci`) was 3/3 green too. The CI forensics rule
(OBS-010: green logs deserve scrutiny) sent the check-run annotations
API one level deeper, where EVERY action-consuming job carried:

> `[warning] Node.js 20 is deprecated. The following actions target
> Node.js 20 but are being forced to run on Node.js 24:
> actions/checkout@v4, actions/cache@v4, gitleaks/gitleaks-action@v2`

Deadline (verified against GitHub's changelog + gitleaks v3 notes):
node20 is removed from hosted runners **2026-09-16 — 11 days out**.
checkout@v4 is the first step of 10 of 13 jobs: the pipeline would
have gone fully red with zero repo-side changes (ADR-018, OBS-011).

## What was delivered

1. **Action runtime migration (ADR-018, commit a22302b)**:
   `actions/checkout@v4 → v7` (10 uses), `actions/cache@v4 → v6`
   (2 uses), `gitleaks/gitleaks-action@v2 → v3` (1 use). Version
   targets verified via each action's `action.yml` `runs.using`
   BEFORE editing; current majors chosen over oldest-node24 majors
   because the backport lines carry the same breaking change anyway
   and our usage touches no documented breaking surface (plain
   `pull_request`, default ref, standard cache inputs).
   `shivammathur/setup-php@v2` verified already-node24 — untouched.
   arch-smoke / hermetic-smoke clone with plain git (node-free) —
   untouched.
2. **Live-gate transient retry (ADR-019, commit 4eacd11)**: during
   verification the main tip push (33923179031) failed the live-LLM
   smoke on Google's documented-transient `503 UNAVAILABLE "high
   demand"`; the job re-run passed one minute later (transience
   proven, OBS-012). The gate now retries ONLY the transport class
   (blocked reason `llm_unavailable`), max 3 attempts, 20s apart,
   with `::warning::` annotations per retry; quota/invalid-key/
   region/model/wiring failures fail immediately; skips still
   hard-fail; a persistent transient still fails red. All three paths
   simulated locally before commit.
