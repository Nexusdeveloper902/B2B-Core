## Discoveries
- `@php($code = …)` BEFORE `@extends` in a Blade error view renders
  EMPTY output (LEN=0) — the 404 file's order (@extends first, @php
  after) is load-bearing. Recorded here for the next error-page author.
- Desk fetches never send Accept-Language, so server-side API messages
  in inline boxes render EN under ES session locale — pre-existing,
  now visible next to the localized toasts (TASK-036 follow-up).
- A stale `artisan serve` from an earlier session survived on :8000
  and serves pre-edit code; `./run serve` fails to bind with only a
  console line. Kill the ports before visual verification.
- The e2e's local-env coupling (classifier driver) was invisible while
  .env held the stub driver; TASK-031's deepseek flip exposed it.
