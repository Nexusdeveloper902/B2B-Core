## What was delivered

**Windows as an auto-detected fallback — one suite, no fork (ADR-017).**

1. **Detection layer** in `scripts/_lib/common.sh`: `detect_os()` →
   `B2B_OS` (`uname -s`: `MINGW*/MSYS*/CYGWIN*` ⇒ windows; WSL ⇒ linux,
   it runs the same ELFs). An explicit `B2B_OS` env var wins — the seam
   the new tests use to simulate Windows on any OS. `is_windows()` guards
   every Windows branch; Linux paths byte-identical.
2. **OS-aware candidates, same chain order**: the Linux ELF `.tools/php`
   is NEVER probed on windows; Composer additionally probes
   `composer.bat`/`composer.cmd`/`composer.phar` spellings (bash cannot
   auto-resolve `.bat` by name). `resolve_composer`/`composer_cmd` gained
   dual modes: phar via `$PHP_BIN`, Windows wrappers direct.
3. **Windows mechanics guarded, not forked**: venv `Scripts/` layout,
   `taskkill //F //T //PID <winpid>` via Git Bash `/proc/<pid>/winpid`
   as the pkill fallback, `python3 → python → py` resolution.
4. **`./run toolchain` degrades honestly on windows**: composer.phar
   only; refuses the Linux ELF static PHP with winget/choco/php.net
   guidance. resolve_php + doctor print the same Windows guidance.
5. **`run.cmd`** (new): cmd/PowerShell thin delegator — locates Git Bash
   (B2B_BASH override → well-known paths → PATH), forwards every arg to
   the SAME bash dispatcher; routes no commands itself. CRLF, pure-ASCII
   echoes. **`.gitattributes`** pins the line-ending contract (`.sh` +
   `run` LF; `.cmd`/`.bat` CRLF) merged with the existing skeleton rules.
6. **e2e portability fix**: test image moved from `mktemp /tmp/...` to a
   project-relative path — native Windows curl.exe cannot read msys
   `/tmp` paths.
7. **Tests**: +10 Windows contracts in ScriptSuiteTest (source +
   behavioral `B2B_OS=windows` simulations + linux counter-test + run.cmd
   + gitattributes + CI job + docs); cross-platform guards so the whole
   file passes on both OSes. Local: 129 passed / 1 skipped (live-LLM
   opt-in), quality green, e2e 22/22, doctor green.
8. **CI `windows-smoke`** (windows-latest, Git Bash, NON-optional): setup
   --ci → doctor → choco shellcheck → quality → test → e2e. The same
   prove-it pattern as arch-smoke / hermetic-smoke.
9. **Docs**: dedicated Windows sections in SCRIPTS.md/.es.md
   (requirements, winget install, run.cmd, degradation table,
   line-ending contract, WSL note) + README quick-start notes EN/ES.
