# RUN-2026-09-15-core-046 — TASK-045 school branding + organization scoping

## What was done
Built in dependency order, because the branding ask could not be honest
without the organization underneath it:

1. **Schema** — `schools` + `school_id` on the 8 root owned tables
   (2 migrations, additive; every column nullable, `NULL` a supported
   value, no data rewrite).
2. **Isolation** — `CurrentSchool` + two global scopes + two model
   traits; wired into 5 root models and 6 child models; `User` left
   unscoped on purpose (guard recursion) with an explicit
   `inCurrentSchool()` for the two surfaces that enumerate accounts.
3. **Leak audit** — 5 raw `exists:` validation rules replaced with
   `OwnedByCurrentSchool` (they queried tables, not models, and walked
   straight past the wall); 4 raw query builders walled by hand
   (leaderboard + the 3 realtime channel readers); `realtime:serve`
   given a per-connection organization.
4. **Branding** — `config/branding.php` + `Brand` + `BrandResolver` +
   `$brand` view share; a six-token brand layer in `tokens.css` with the
   whole primary family derived from it; 14 chrome-on-primary colors
   moved from the gold data accent to `--on-primary`; head-inlined
   override; brand-aware manifest route.
5. **Assets** — the school's own crest processed out of
   `B2B-Logo-Suite/School_Logo.jpeg` into 10 web assets.
6. **Seeders** — realistic dataset bound to one school, operator split
   into `SystemAdminSeeder` and run separately by the script.
7. **Tests, docs, `.agent`.**

## Traps
- **A global scope on `User` recurses forever.** The session guard
  resolves the current user by querying `users`; a scope that consults
  `auth()->user()` while answering that query never terminates. User
  lists are scoped explicitly instead.
- **`exists:` is not scope-aware.** `exists:classes,id` queries the
  TABLE. Every client-supplied foreign key needed the scoped model, or
  a foreign `class_id` would pass validation and only fail silently
  downstream (0 rows updated).
- **A memo that ignores WHO is asking is a leak.** `BrandResolver`
  memoized per object; in a test runner (and under Octane) that object
  outlives one request, so the second account in a test kept the
  first's branding. Memo is now keyed by identity — the bug the brief's
  "no branding leaks between sessions" requirement is about.
- **Bulk inserts bypass creation inheritance entirely.** The realistic
  seeder writes events/roster/recycling rows with
  `DB::table()->insert()`; those never reach a model hook and had to be
  stamped by hand.
- **Creation inheritance is real in tests too.** A user built while
  `actingAs()` a school admin JOINS that school — `['school_id' => null]`
  does not mean "no school", it means "inherit". Build fixtures before
  authenticating, or use `CurrentSchool::withoutScoping()`.
- **`->where(col, null)` matches nothing.** `NULL` is a real data set
  here (the unassigned organization), so every wall branches to
  `whereNull` explicitly.
