## What was done

`env('APP_TIMEZONE', 'America/Bogota')` — COT, fixed UTC−5, no DST.

every rendered clock are the same Bogota local time; API ISO 8601
strings carry the explicit `-05:00` offset. `APP_TIMEZONE` remains the
escape hatch for deployments elsewhere. No route, migration, or device
contract change — the reader's optional `client_timestamp` (any ISO
8601 offset) is honored as-is, exactly as before.
