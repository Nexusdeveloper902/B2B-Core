# RUN-2026-09-06-core-014 — realtime WebSocket dashboard feed (TASK-016)

Owner directive (verbatim): "the dashboard, i want it updated to a
websockets connection so i can see in real time when a student taps
their card instead of having to f5."

## What was done

ADR-026: a hand-rolled, zero-dependency pure-PHP WebSocket server
(`php artisan realtime:serve`, ~270 lines, `stream_select` + own
RFC 6455 codec) polls the **events table** every ~300 ms and pushes
new tap rows to every connected dashboard. The events spine stays the
single source of truth — the tap write path gained zero new coupling
(device protocol byte-identical, verified by empty diff), and any
process sharing the DB (tests, future tools) broadcasts for free.
Laravel Reverb/Echo was rejected: composer + vendored-Pusher-JS + npm
build on a deliberately no-build, no-NPM, hermetic-toolchain LAN
stack (ADR-013 ethos) buys nothing at school scale.

- `app/Services/Realtime/`: `WsFrame` (RFC 6455 codec: lengths
  125/126/65536+, masking, partial buffers, ping/pong), `Handshake`
  (accept-key per the RFC's own worked example, request parse,
  101/denials), `RealtimeToken` (HMAC-SHA256 `userId.expiry.sig`,
  APP_KEY, TTL), `RealtimeFeed` (recent / events-after / head id,
  joined payload — mirrors dashboard-visible data only, no UIDs)
- `RealtimeServeCommand`: accept + authenticate upgrades (401 plain
  HTTP before any framing on a bad token), hello frame with history,
  poll+broadcast, ping/pong/close, SQLite reconnect-on-error
- `GET /realtime/token` (web routes, session-auth + role
  admin/teacher) mints the short-lived token server-side into the
  dashboard render — the socket process never parses sessions
- Dashboard UI (SSR-first): `partials/live-feed.blade.php` on BOTH
  dashboards (rows server-rendered from the same `RealtimeFeed::
  recent()` query the hello frame sends — panel useful with WS down),
  `public/js/realtime.js` (no-build: LIVE/connecting/offline badge
  honesty, prepend+flash, backoff reconnect 1 s→15 s with token
  re-mint, `realtime:tap` CustomEvent), teacher attendance rows flip
  live (Absent→Present/Late, FIRST-tap-wins matching
  `classAttendanceToday`, row flash)
- `./run serve` starts the WS server alongside the web server
  (honest bilingual degrade when the port is busy / server dies /
  B2B_REALTIME=0; EXIT trap tears both down on Ctrl+C); `./run
  status` gains a realtime row; `scripts/_lib/realtime-probe.php` +
  2 e2e checks (24 total)
- Tests (+33): WsFrame 8, Handshake 5, RealtimeToken 6, RealtimeFeed
  3, token route 3, DashboardTest +5 (SSR panel, waiting state,
  teacher rows, ES, the TASK-014 escaping lesson applied to the
  attribute-JSON bootstrap), **RealtimeServerTest 2 — real sockets
  against the real command process** (hello+history, live broadcast
  after an out-of-band row insert, 401 on a bad token)
- Docs: SCRIPTS.md/.es.md serve realtime line + env knobs;
  `.agent/ARCHITECTURE/realtime-feed.md` (protocol contract)
