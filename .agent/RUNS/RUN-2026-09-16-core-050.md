## CI follow-up
- **What failed:** on the first push (`f28dbdd`), only the gitleaks job
  failed. Every other job passed, including the MariaDB, Windows and
  Real-HTTP E2E jobs.
- **Cause:** `generic-api-key` flagged 7 fabricated `PLS-…` credential
  ids that sit next to `credential_uid` in the docs and tests. None of
  the key or MAC literals was flagged.
- **Fix:** `fdc5575` allowlists the `PLS-[0-9A-Z]{12}` format (entry 8).
  These ids are public by design (App ADR-001). CI is fully green.
