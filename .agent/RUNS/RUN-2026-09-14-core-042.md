## Discoveries
- Dotted settings keys are NESTED paths to Laravel's validator: a flat
  ['pae.breakfast_start' => …] payload looks EMPTY to the
  'pae.breakfast_start' rule — build the nested array with data_set
  before validating (ADR-055).
- dompdf's stream() echoes directly and bypasses Laravel's response
  pipeline (Content-Type ends up text/html) — return
  response($dompdf->output()) with explicit headers instead (ADR-056).
- DemoSeeder's new past-day scenario rows leak into every test that
  counts events — fixtures now wipe events after seeding (the fixture
  owns its data); same for the e2e journey (today stays clean).
- The e2e relabel→meal flow needs attendance BEFORE the relabel (a
  PAE-mode reader no longer records CLASS_ATTENDANCE taps), a
  day-safe client_timestamp pair (now-10m/+5m), and weekday/weekend
  branching — CI runs on any day.
- Shell: an apostrophe inside a single-quoted PHP -r block ("Ana's")
  closes the shell quote — bash -n catches it; also eval of values
  containing spaces needs escapeshellarg.
