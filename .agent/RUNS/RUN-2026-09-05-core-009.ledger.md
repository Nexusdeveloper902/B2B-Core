## Defects found and fixed during the run

  getStatus(); same class earlier had a protected-collision with
  TestCase::reader()

  was negative → max(0,…) = 0 → fixed to now()->diffInSeconds(expires)
  in BOTH controllers (caught by the countdown bounds test)

  one global ticker started once, tick() no-ops when disarmed
