## Defects caught mid-run (mine, fixed immediately)

- My rewrite first used escaped `{{ json_encode() }}` for the new
  templates → broke the script unconditionally in the live browser
  (0 polls) → which is what exposed the ORIGINAL lastSeenUid bug for
  what it was; switched all to `{!! json_encode() !!}`.
- My comment text contained literal blade brace pairs → compiled to
  `<?php echo !!}` → "Unmatched '}'" view error → reworded (blade
  parses braces even inside JS comments — environment lesson).
- `git stash` + live-render proof cycle needed view:clear between
  edits (stale compiled views masked the fix).
