## Environment lessons (this run)

- PHPUnit 12 has FINAL TestCase methods that collide with natural test
  helper names: `status()` (returns TestStatus) silently breaks
  response chains with "Call to undefined method
  TestStatus\Unknown::assertOk()" — and my sed rename missed
  chained `->status()` calls. grep the whole file after such renames.
- Carbon 3's diffInSeconds is SIGNED: `$future->diffInSeconds(now())`
  is NEGATIVE. Countdowns must be `now()->diffInSeconds($future)` —
  the bounds test caught it because 0 is not > 0.
- JS polling restarts multiply timers: a `startPolling()` that also
  starts the 1 s ticker stacks intervals on every restart. One global
  ticker, started once, no-ops when idle.
