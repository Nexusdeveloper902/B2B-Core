# RUN-2026-09-13-core-040 — Marketplace panel/overflow/translations + Core search hardening

Owner (chat, 2026-09-13), three items: (1) "Translation is still
incomplete in places where it's not exactly HTML, but like animations,
and also inside the marketplace as a whole"; (2) the marketplace
landing's first "Tap/Toque" panel — "the gate reader is too far off to
the right and it goes off screen"; (3) "the search bar … doesn't really
work (you shouldn't need to press enter or anything)".

## Diagnosis
- (1) Two hardcoded English strings in the landing's demo panels —
  "who + where = one event" (step 2) and "recorded" (step 3 snippet) —
  everything else on the landing is lang-keyed or a technical artifact
  (GATE-A, 0441, attendance.in — event identifiers by design). Core JS
  audited: realtime.js strings ride the server-localized boot map
  (RUN-030); motion/markdown have none; toast.js had one hardcoded
  aria-label ("Notifications").
- (2) Geometry audit at 1366/1100/900/768/640/390px: NOTHING actually
  overflows the viewport anywhere — but `justify-content:
  space-between` pinned the GATE-A reader box flush against the
  ledger panel's right border (2px), which against the screen margin
  reads as "too far right / going off screen" (the owner's wording).
- (3) Every Core search (students, pairing, teacher ×2, parent
  timeline) is already live-on-input — verified empirically by typing
  with no Enter (all filter correctly). The "needs Enter" experience
  matches the students desk's silent-fetch-failure path: when the
  server was unreachable (bench restart windows), the live search's
  `.catch` kept stale rows with zero feedback, and pressing Enter did
  a full GET reload that "worked".

## Changes
- **Marketplace** (repo B2B-Marketplace, RUN-2026-09-13-marketplace-017):
  - `.tap-visual` centers the card+reader pair with a bounded gap
    (`clamp(48px, 16%, 150px)`) and 28px insets — the reader now sits
    80px inside the panel edge (was 2px), measured at 1366.
  - `ledgerLoop.distance()` measures the REAL layout gap
    (`target.offsetLeft - cardEnd`, transform-free) instead of assuming
    max-spread — correct for any layout change.
  - Landing translations: `identify_join_prefix` / `identify_join_event`
    / `stamp_recorded` keys (EN+ES); view uses them.
  - Branded 404 (`resources/views/errors/404.blade.php` + `.nf-*` CSS +
    `common.not_found_*` EN/ES) — unknown URLs no longer render
    Laravel's bare page.
- **Core** (this repo):
  - Students desk live search degrades gracefully: on fetch failure it
    client-filters the already-rendered rows (same pattern as the
    pairing desk), hides the server-driven pager while the fallback is
    active, and a successful round-trip restores it. The search box can
    never feel dead again.
  - toast.js region `aria-label` now rides `PulseToastLabels.region`
    (new `toast_notifications` key EN/ES) — no hardcoded English in the
    feedback layer.
