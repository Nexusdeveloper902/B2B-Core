## Owner request

> "Using the same stateless prompt architecture, design scripts (Linux
> support prioritized, Arch specifically) so the running of this app doesn't
> consist of 10 different commands but a collection of properly done, well
> documented scripts."

## What was delivered

`./run` — a single dispatcher with 11 subcommands (setup, serve, test, e2e,
quality, doctor, status, reset, model, toolchain, ci, help), each delegating
to a standalone documented script under `scripts/`, all sharing
`scripts/_lib/common.sh`. Bilingual EN/ES output and documentation. Arch-first
diagnostics with machine-verified remediation; hermetic zero-system toolchain
fallback. 20-test PHP guard + three new CI jobs that keep the suite honest.

The 10-command manual flow is now: `./run setup && ./run serve` (plus one
command per operation thereafter — see docs/SCRIPTS.md).

## How the stateless architecture was applied to ops

- No command assumes a previous command ran: every script verifies its own
  preconditions and resolves its own interpreter (ADR-011).
- The filesystem is the only state (vendor/, .env, APP_KEY, migrations) —
  no state files that can go stale.
- Fail-loud with the fix printed bilingually (ADR-011).
- Destructive operations guarded (reset asks; e2e uses a throwaway DB).
- CI dogfoods the exact commands users run, on clean checkouts, on three
  different environments (ubuntu matrix, real Arch container, no-PHP container).

## Key decisions

- ADR-009: dispatcher + standalone scripts (Makefile/just/composer-scripts
  rejected with reasons).
- ADR-010: system-PHP-first with Arch-aware doctor + hermetic `.tools/`
  fallback; resolution chain B2B_PHP → PATH → .tools; Composer always invoked
  through the resolved PHP (it is a phar — works with no php on PATH).
- ADR-011: idempotent, self-diagnosing scripts; .env never overwritten.

## Findings fixed during verification (repository reality > claims)

1. **PHP_FAIL_REASON lost in command substitution** — subshell side effects
   don't propagate; refactored php_valid to set the reason in the caller's
   shell.
2. **Composer "not usable" without system PHP** — Composer is a phar; every
   invocation now goes through the resolved PHP (composer_cmd).
3. **phpunit suite-name casing** — `--testsuite=unit` found nothing; mapped
   lowercase args to Unit/Feature/E2E.
4. **Model server daemonization** — backgrounded nohup job kept the script
   blocked in wait() when output was piped; fixed with exec+disown+full fd
   closure; pidfile now records the authoritative (post-exec) pid via pgrep;
   stop verifies actual shutdown via the health endpoint.
5. **FunctionRegistryTest midnight flakiness (PRE-EXISTING)** — "minutes ago"
   fixtures crossed the date boundary after 00:00, failing 4 tests; fixed by
   freezing test time (travelTo). This flake would have broken CI on any
   post-midnight run of TASK-002's code.
6. **bootstrap/app.php Pint finding (PRE-EXISTING)** — surfaced by the new
   quality gate; fixed (imports hoisted, style-only).
