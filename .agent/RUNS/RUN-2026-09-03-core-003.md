## Why the Actions tab was empty (diagnosis, not guesswork)

Two stacked defects since the first push of ci.yml (5d70054), both
documented in OBS-005 / ADR-012 / TASK-004 with API evidence:

1. `name: Lint (quality gate: Pint + ...)` — a colon+space inside an
   unquoted YAML value → invalid YAML → GitHub registered the file under
   its path with NO name and NO triggers → zero runs, dispatch 422.
2. `if: ${{ secrets.GEMINI_API_KEY != '' }}` at job level — `secrets` is
   not allowed in job-level `if` → would have kept the workflow dead even
   after fixing the YAML.

Fixes: quoted display names; canonical `llm-gate` job pattern (secret read
in job `env`, gating via `needs.llm-gate.outputs.enabled`); **workflows-lint
job running actionlint as a permanent guard**; `permissions:
contents: read`; concurrency group; per-job timeouts.
